eaSplit 0.1.0-beta.5 is a signed and Apple-notarized beta for macOS 15 or
later, supporting Apple silicon and Intel Macs.

## What’s new

- Adds an optional focus mode that hides other visible applications after a
  successful split. Applications stay running, and the setting is off by
  default.
- Keeps selected applications visible across consecutive splits, including
  when a newly selected application was hidden by the previous focus split.
- Extends Undo to restore both the previous window geometry and only the
  application visibility changed by the latest split.
- Leaves Finder, background-only processes, applications that were already
  hidden, and every selected application untouched.
- Reports hide or restore failures without discarding an otherwise successful
  window arrangement, and retains failed Undo work for another attempt.

No account, analytics, advertising, cloud sync, or network service is included.
See `release-manifest.json` for the exact source commit, checksums, notarization
identifiers, and build-tool versions.
