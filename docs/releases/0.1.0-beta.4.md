eaSplit 0.1.0-beta.4 is a signed and Apple-notarized beta for macOS 15 or
later, supporting Apple silicon and Intel Macs.

## What’s new

- Suggests frequently repeated application combinations after two successful
  splits. Learning stays on the Mac, and any suggestion can be dismissed.
- Brings every successfully arranged window forward by default, while keeping
  the first selected window focused. The behavior can be disabled in Settings.
- Adds true edge-to-edge placement alongside the configurable window gap.
- Makes Settings open as a single active window without opening another picker.
- Improves launch-at-login state handling, Accessibility permission recovery,
  slow-window resizing, repeat, undo, and release verification.

No account, analytics, advertising, cloud sync, or network service is included.
See `release-manifest.json` for the exact source commit, checksums, notarization
identifiers, and build-tool versions.
