Help with the beta.

Start with the exact symptom. Most setup issues are permission or window eligibility issues.

Accessibility says “waiting”

  1. Open System Settings → Privacy & Security → Accessibility.
  2. Confirm the production eaSplit app is enabled, not only eaSplit Development.
  3. Return to eaSplit and select Check Again.
  4. If it still waits, quit eaSplit, reopen it from Applications, and check again.

A window is missing

eaSplit lists normal, visible, movable, resizable windows. Full-screen windows, minimized windows, dialogs, fixed-size panels, and nonstandard windows are excluded. Bring a normal app window onto the current desktop and refresh the picker.

A layout leaves space

Open eaSplit Settings. Turn on Fill screen edge to edge to remove both the boundary gap and the gap between arranged windows. Keep it off if you prefer a configurable visual gap.

A saved recipe is unavailable

Recipes use applications that are already running. Open every application in the recipe, make sure each has an eligible window, then refresh and try again.

Report a beta issue

Use the same invitation channel that gave you this beta and include:

  • eaSplit version and build number
  • macOS version and Mac model
  • the layout and ratio you selected
  • which applications were involved
  • the exact message or visible result

Do not include private document contents or sensitive window titles.
