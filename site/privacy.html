Privacy, in plain language.

No account. No analytics. Nothing leaves your Mac.

Scope

This statement describes the eaSplit macOS app. This website is hosted by GitHub Pages and uses no analytics or third-party runtime resources. GitHub records visitor IP addresses for security purposes as described in the GitHub Privacy Statement.

What eaSplit sees

With Accessibility permission, eaSplit can see the names, owning applications, positions, and sizes of eligible on-screen windows. It uses window titles only to distinguish choices in the picker. It does not read the content inside a window.

What eaSplit stores

Saved recipes contain the recipe name, application names and bundle identifiers, layout, ratio, and slot order. They are stored locally in ~/Library/Application Support/eaSplit/recipes.json. Preferences and the last arrangement are stored in the standard local macOS preferences system.

Window titles are not stored in recipes.

What eaSplit sends

Nothing. This beta has no account, analytics, advertising, cloud sync, or network service. Its diagnostic logging records only counts and success or failure totals, not window titles or document content.

Your control

  • Remove individual saved recipes from eaSplit.
  • Revoke Accessibility permission at any time in System Settings.
  • Remove all saved recipes by deleting the local eaSplit Application Support folder after quitting the app.

Questions

During the private beta, use the same invitation channel that provided your download. Include the app version and macOS version, but do not send private window titles or documents.
