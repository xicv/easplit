Install eaSplit.

A signed, Apple-notarized beta for macOS 15 or later.

Before you begin

Version
0.1.0 beta 5 (build 5)
Compatibility
macOS 15 or later, Apple silicon and Intel
Permission
Accessibility, so eaSplit can move and resize the windows you choose
Download free beta View SHA-256

Install

  1. Open the downloaded eaSplit-0.1.0-beta.5.dmg.
  2. Drag eaSplit onto the Applications shortcut.
  3. Eject the eaSplit disk image, then open eaSplit from your Applications folder.
  4. Select Request Access. In System Settings, enable eaSplit under Privacy & Security → Accessibility.
  5. Return to eaSplit and select Check Again if approval is not detected immediately.

macOS should identify this download as notarized software from an identified developer. If it reports a damaged app or an unidentified developer, stop and report the exact message through the invitation channel instead of bypassing Gatekeeper.

What’s new in beta 5

  • An optional focus setting hides other visible apps after a successful split.
  • Undo restores only the apps eaSplit hid; those apps continue running in the background.
  • Frequent application combinations can be suggested after two successful splits.
  • Successfully arranged windows come forward by default, with slot 1 focused.

Your first split

  1. Open two normal, resizable app windows.
  2. Select the eaSplit icon in the menu bar.
  3. Choose the two windows, the Columns layout, and the 50/50 ratio.
  4. Enable Fill screen edge to edge in Settings if you prefer no outer or center gaps.
  5. Select Split. Save the combination if you want to reuse it.

Verify the download

The adjacent checksum file contains the SHA-256 for these exact beta bytes.

In Terminal, run:

shasum -a 256 ~/Downloads/eaSplit-0.1.0-beta.5.dmg

Its value must match the published checksum.
